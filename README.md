# Student Academic Performance Analysis and Visualization System

## Project Overview
This project is an academic analytics platform developed using MySQL, Python, Flask, and Power BI. The system analyzes student academic performance, attendance, GPA trends, and risk levels through interactive dashboards and REST APIs.

---

## Technologies Used
- Python
- Flask
- MySQL
- Power BI
- SQL
- HTML/CSS
- Git & GitHub

---

## Features
- Role-based login system
- Executive Dashboard
- Faculty Dashboard
- Coordinator Dashboard
- Student Drill-Down Analysis
- GPA and Attendance Analysis
- Risk Classification
- REST API Integration
- Interactive Power BI Visualizations
